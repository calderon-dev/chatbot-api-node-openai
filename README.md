# Business Chatbot API

This project is a **Node.js + Express** application that integrates with **OpenAI** to provide a chatbot for business support.  
It demonstrates how to build a REST API that connects to an AI model, making it a strong portfolio example of backend + AI integration.

---

## 🚀 Features
- Chatbot endpoint (`/api/chatbot`) that responds to user queries.
- Contextual business information (location, hours, products).
- Secure API key management with environment variables.
- Error handling and input validation.
- Frontend form (HTML/CSS/JS) to interact with the chatbot.
